# PassGuard-Multiplatform

A multiplatform password manager app that targets Android, iOS and Desktop (Windows, MacOS and Linux).
Written using Kotlin Multiplatform along with Compose Multiplatform for shared UI.

Features a secure storage with strong encryption and a slick Material3 Design.

𝙁𝙚𝙖𝙩𝙪𝙧𝙚𝙨:
- 98% of shared code
- Shared UI
- Platform specific features like storage, encryption, file management, and clipboard
- CI/CD
- Unit Tests that cover all business logic and run in GitHub Actions pipelines
- End-to-End tests that run on Firebase Test Lab
- Clean Architecture
- UI components reusability
- UI design language with a strong accent on expandable item
